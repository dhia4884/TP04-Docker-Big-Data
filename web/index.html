TP04: Docker & Big Data

Containerized analysis of a large air quality dataset.

Dataset: Air Quality Measurements
Data size: Approximately 5.58 GB
Records: 66,937,826
Features: 12 columns
Technology: Docker, Docker Compose, Python

Project objectives

  • Run data analysis inside a Docker container.
  • Mount the dataset as a read-only volume.
  • Manage containers and networking.
  • Expose services through mapped ports.
