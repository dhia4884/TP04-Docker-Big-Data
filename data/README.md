# Dataset Information

The application uses the Air Quality dataset:

- File name: air_quality_5gb.csv
- Approximate size: 5.2 GiB
- Number of records: 66,937,826
- Number of columns: 12

The CSV dataset is not included in this Git repository because of its large size.

Place the dataset in this directory before running the application, or update the volume path in compose.yaml to point to its actual location.

The dataset is mounted into the Docker container as a read-only volume.
